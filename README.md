# Aventura no Othelo Franco

Jogo 2D de navegador ambientado na EMEF General Othelo Franco (R. Jarinu, Tatuapé, São Paulo). O estudante novo passa o primeiro dia na escola: faz a matrícula, conhece a equipe, participa das aulas com minijogos e, no fim, tenta descobrir o nome da colega que o ajudou o dia todo.

## Como jogar

Abra `index.html` em qualquer navegador. Não precisa instalar nada; o jogo é um arquivo só.

O jogo escolhe a versão sozinho pelo aparelho:

- **Computador:** W, A, S, D para andar, E para conversar e jogar, M para o minimapa.
- **Celular e tablet:** botões na tela, tela cheia e menu.

Para forçar uma versão, acrescente ao endereço `?versao=computador`, `?versao=celular` ou `?versao=tablet`. O link "Versão" no rodapé (computador) ou no menu (celular e tablet) faz o mesmo.

O progresso fica salvo no próprio navegador.
